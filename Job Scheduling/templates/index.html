Scheduling Paradigms: Greedy vs. Dynamic Programming

Explore how greedy heuristics and dynamic programming address complex multi-criteria optimization in process dispatching.

Greedy Approach O(n log n)

Local Optimum Strategy

Makes immediate locally optimal choices at each decision timestamp without backtracking. Highly scalable with low latency.

  • ✓ FCFS: Fair FIFO sequence
  • ✓ SJF / SRTF: Minimizes average waiting time
  • ✓ Priority (P / NP): Critical task urgency
  • ✓ EDF: Optimal dynamic real-time deadlines
  • ✓ Profit Sequencing: Disjoint-set greedy deadline slotting
Dynamic Programming O(n log n) - O(n·W)

Global Optimal Substructure

Solves overlapping subproblems and memoizes optimal decisions to guarantee the globally maximum revenue under constraints.

  • ✓ Weighted Interval: Non-overlapping max-profit subset
  • ✓ Binary Search memoization: Logarithmic compatibility
  • ✓ 0/1 Knapsack: Exact workload budget optimization
  • ✓ Traceback Reconstruct: Full state recovery
